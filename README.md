# VideoDownloader

Android downloader prototype, built with Kotlin. Downloads direct HTTPS MP4, WebM, MOV and M4V video file links using Android DownloadManager. No external server is required.

**Current limitation:** YouTube, TikTok, and X page links are not supported yet; they require media extraction functionality.

## Get APK

Open GitHub Actions > Build Android APK > latest successful run > Artifacts > VideoDownloader-debug-apk.

Only download content you have permission to download.
